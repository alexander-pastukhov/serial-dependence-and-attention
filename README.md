# Serial dependence and attention
Data and analysis for dual-task serial dependence

## Notebooks
- 01_analysis_...: load data and prepare for fitting, fit individual models, compute model comparisons and generate summaries for predictions.
- 02_:
  - central_task: plot central task performance across all experiments per participant.
  - parameter_posterior_distribution_plots: plot averages and posterior predictions across all experiments.
  - parameter_distribution: compute additional descriptive statistics for posterior predictions.
  - loo-tables: combine model comparisons for all experiments.


## Sampled draws and Figures
